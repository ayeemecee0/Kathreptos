# Katoptron (Κάτοπτρον)

Nationwide public accountability project focused exclusively on Flock Safety and automated license plate recognition (ALPR).

## Components
- Synthetic surveillance simulator: fictional vehicle observations, not actual people's movements.
- Public records: sourced contracts, agency decisions, legislation, and documented executive roles.
- Discovery pipeline: potential leads are reviewed before publication.

## Development status
Prototype v0.3 exists as a local package, but is **not yet uploaded to this repository or deployed**. The planned stack includes a standalone HTML prototype, Supabase SQL migration, and a Python discovery script.

## Data safeguards
Do not collect or publish private license plates, targeted movement histories, or residential locations. Separate simulation data from public accountability records. Never commit Supabase service-role keys.
